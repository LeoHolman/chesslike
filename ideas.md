# Better SVG Creator for Piece Icons

## Current status
The custom-piece SVG editor is now in a solid state for this project: thin line art is preserved, strokes are filtered and simplified, symmetry/snap tools are available, templates can be applied, and the board preview matches the editor more closely.

## Future improvements
- Pressure-sensitive width if tablet input is added later
- Layer support for details and base shapes
- Auto-detect whether an imported SVG is mostly line art or a filled silhouette
- Additional piece icon templates for common chess-like roles
